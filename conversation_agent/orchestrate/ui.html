How do I register an application in Microsoft Entra ID?
AI

Register an application in Microsoft Entra ID

Quick answer: Registering an app creates a service principal in your tenant and gives the app credentials to authenticate users or call APIs.

Prerequisites

  • An active Azure subscription with a Microsoft Entra ID (formerly Azure Active Directory, or AAD) tenant.
  • A user account with the Application Administrator or Global Administrator role.
  • The redirect URI for your application (e.g. https://localhost:3000/callback).

Steps

  1. Sign in to the Microsoft Entra admin center.
  2. Go to Identity › Applications › App registrations.
  3. Select New registration.
  4. Enter a display name for your application.
  5. Under Supported account types, choose who can use the app.
  6. Add your Redirect URI and select the platform (Web, SPA, or Mobile).
  7. Select Register. Copy the Application (client) ID and Directory (tenant) ID.
  8. Go to Certificates & secrets and create a client secret. Store it immediately — it will not be shown again.

Verify

  • The app appears in the App registrations list with the name and client ID you set.
  • Under Overview, confirm the tenant ID matches your directory.

AI

Configure API permissions and grant admin consent

Quick answer: API permissions declare which resources your app can access. Admin consent approves those permissions tenant-wide so users are not individually prompted.

Steps

  1. In App registrations, open your app and select API permissions.
  2. Select Add a permission.
  3. Choose Microsoft Graph or another API your app requires.
  4. Select Delegated permissions for user-signed-in scenarios, or Application permissions for daemon scenarios.
  5. Search for and select the permissions your app needs (e.g. User.Read, Mail.Send).
  6. Select Add permissions.
  7. Select Grant admin consent for [your tenant], then confirm. The Status column shows a green checkmark.

Verify

  • Each permission shows Granted for [tenant] with a green ✓ in the Status column.
